## Cài đặt `Lombok`
1. Thêm dependency vào `pom.xml`

```xml
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <version>1.18.42</version>
</dependency>
```

2. Reload all Maven project
